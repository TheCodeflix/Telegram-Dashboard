1. CREATE plugins/telegram_client.py:
   - Function: create_client(session_string)
     * Initialize Pyrogram client with in-memory storage
     * Return client object
   - Function: test_connection(client, session_string, password=None)
     * Try to connect and get user info
     * Return success status and user_info dict
   - Function: get_all_dialogs(client)
     * Get all chats, channels, groups, users
     * Return formatted list with type, id, title, username
   - Function: get_user_info(client)
     * Get current user info (name, username, id, photo)
     * Return dict

2. CREATE plugins/channel_utils.py:
   - Function: format_dialog(dialog)
     * Extract: id, title, username, type, photo_url, member_count
     * Return dict
   - Function: get_dialog_type(dialog)
     * Return 'channel', 'group', 'supergroup', 'bot', 'user'
   - Function: sort_dialogs_by_type(dialogs)
     * Group dialogs by type
     * Return dict with keys: channels, groups, contacts, bots

     * Create client using telegram_client.create_client(session_string)
     * Connect to Telegram
     * Get user_info using telegram_client.get_user_info()
